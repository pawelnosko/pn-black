<h1>NØR – Luxury Fashion Theme for OpenCart 4</h1>
<p><strong>Minimalism. Fashion. Modern E-Commerce.</strong></p>
<p>NØR is a premium editorial-style theme for OpenCart 4, designed to transform traditional online stores into sophisticated digital shopping experiences.</p>
<p>Inspired by luxury fashion magazines, contemporary typography, and minimalist design, NØR combines large-scale photography, elegant product presentations, generous whitespace, and subtle gold accents.</p>
<p>Unlike conventional OpenCart themes, NØR includes a dedicated administration panel for managing homepage sections, curated collections, brand content, testimonials, and newsletter subscriptions.</p>
<p><strong>Less visual noise. More brand identity.</strong></p>

<h2>📦 Installation</h2>
<ol start="1">
<li>
<p>Back up your OpenCart files and database.</p>
</li>
<li>
<p>Open the Extension Installer in your OpenCart administration panel.</p>
</li>
<li>
<p>Upload <code>pn_black.ocmod.zip</code>.</p>
</li>
<li>
<p>Navigate to <strong>Extensions → Themes</strong>.</p>
</li>
<li>
<p>Locate and install <strong>Theme Black</strong>.</p>
</li>
<li>
<p>Activate and configure the theme.</p>
</li>
<li>
<p>Customize homepage sections, images, collections, and brand content.</p>
</li>
<li>
<p>Verify storefront functionality and responsive layouts.</p>
</li>
</ol>
